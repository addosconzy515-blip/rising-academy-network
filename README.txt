RISING ACADEMY NETWORK WEBSITE

Files: index.html, about.html, admissions.html, academics.html, staff.html, gallery.html, news.html, contact.html, style.css, images/

To publish on GitHub Pages: upload ALL files and the images folder to the ROOT of a public repository. Ensure index.html is at the root. In Settings > Pages choose Deploy from a branch, branch main, folder /(root), and Save.

Before publishing, replace the phone/email placeholders in contact.html and confirm the school has permission to publish learner photos. The sample contact form is not connected to send messages.
